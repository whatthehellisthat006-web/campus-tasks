# Campus Tasks

Projet d'API de gestion de tâches étudiantes, utilisé dans les ateliers DevOps.

## Démarrage

Cet atelier prépare la structure du projet et son historique Git. Le code de
l'API sera ajouté dans les ateliers suivants ; aucun service n'est encore exécutable.

Le fichier `.env.example` fournit les valeurs d'exemple. Les valeurs locales
se placent dans `.env`, qui est ignoré par Git et ne doit jamais être publié.

## Santé du service

Point prévu : `GET /health`.
